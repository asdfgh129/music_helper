# 判定规则

> 本文负责：文件名、标签完整性、文件名/标签一致性、重复、歌词、归档、报告的所有判定规则。
> 本文不负责：流程顺序（见 [workflow.md](workflow.md)）、命令行参数（见 [usage.md](usage.md)）、
> 阈值与扩展名的配置位置（见 [configuration.md](configuration.md)）。

每条规则只在一个模块实现；修改规则时改对应模块并补 `tests/` 用例。

## 1. 文件名规则

唯一实现：`core/naming.py`。

### 1.1 规范格式

```
<歌手> - <歌名>.<扩展名>
```

`is_canonical()` 要求文件名同时满足：能解析出歌手、能解析出歌名、包含 ` - `（空格-空格）。

### 1.2 解析

`parse_filename()` 的优先级：

1. 先按第一个 ` - ` 分割；
2. 没有 ` - ` 时按第一个 `-` 分割；
3. 都没有时歌手为空、整段作为歌名。

### 1.3 规范化

`canonicalize()` **只**在「恰好一个 `-` 且没有 ` - `」时把分隔符改成 ` - `：

| 原名 | 结果 |
|---|---|
| `周杰伦-晴天.flac` | `周杰伦 - 晴天.flac` |
| `AC-DC - Back.flac` | 不改（已经有 ` - `） |
| `A-B-C.flac` | 不改（多个 `-`，可能是名字本身） |

`format_filename()` 会清理 `\ / : * ? " < > |` 等非法字符，并按需拼接扩展名。

### 1.4 版本标记

`version_markers()` 从**括号内容**里识别版本类别：

| 类别 | 同义词 |
|---|---|
| `live` | live、现场、演唱会、concert |
| `remix` | remix、混音、dj、bootleg、rework |
| `instrumental` | instrumental、伴奏、karaoke、offvocal、纯音乐 |
| `acoustic` | acoustic、unplugged、不插电 |
| `demo` | demo、小样、session、outtake、未发行 |
| `cover` | cover、翻唱 |
| `feat` | feat、featuring、ft.、ft |

`version_key()` 保留这些标记，只去掉下载序号与其他无关括号：

| 输入 | 去重键 |
|---|---|
| `晴天` | `晴天` |
| `晴天 (1)` | `晴天` |
| `晴天 (Live)` | `晴天\|live` |
| `晴天（现场版）` | `晴天\|live` |

去重键由 `Track.key` 使用，因此 Live/Remix/伴奏版不会因为名字相似被直接当成同一首。

## 2. 标签完整性

唯一实现：`core/tags.py: missing_tag_fields()`。

检查五个字段：歌曲名、歌手、专辑、年份、封面。返回缺失项的中文名列表。

严重级别只在检查阶段使用：

| 缺失项 | 级别 | 处理 |
|---|---|---|
| 歌曲名、歌手 | `severe` | `--fix` 时可移入 `INCOMPLETE_DIR` |
| 专辑、年份、封面 | 提示 | 只进报告，不移动文件 |

### 2.1 待补全判定

唯一实现：`core/check.py: readiness_problems()`。

- 必须有歌曲名、歌手、专辑、年份；
- 文件名与标签不能矛盾（见第 3 节）；
- **封面、歌词不参与判断**。

任何一项不满足就移入 `INCOMPLETE_DIR`，其余文件留在 `WORKSPACE_DIR`。
这与「标签完整性」不是同一件事：后者用于报告与 `--fix`，前者只决定分流。

## 3. 文件名与标签一致性

`core/check.py: _consistency_problem()`：

- 歌手：两边都能解析时，拆分多艺术家后做交集；交集为空才算矛盾；
- 歌名：去空白、转小写后比较；完全相同或互为子串不算矛盾；
- 任一侧为空时跳过该维度。

示例：

| 文件名 | 标签 | 结果 |
|---|---|---|
| `周杰伦 - 晴天.flac` | artist=周杰伦, title=晴天 | 一致 |
| `周杰伦 - 晴天.flac` | artist=林俊杰 | 歌手矛盾 |
| `Jay - 晴天.flac` | artist=Jay Chou | 一致（子串） |
| `周杰伦 - 晴天 (Live).flac` | title=晴天 | 一致（子串） |

## 4. 重复判定

唯一实现：`core/dedupe.py`。

### 4.1 两条规则

| 规则 | 键 | 说明 |
|---|---|---|
| 标签维度 | `歌手 + 歌名`（版本感知） | 两个字段都取自标签；歌名为空则跳过 |
| 文件名维度 | 去掉 `(1)(2)` 下载序号的文件名主干 | 保留 `(Live)` 等版本括号 |

两条规则都要求**时长差 ≤ `DURATION_TOLERANCE`**（默认 3 秒）。

- 时长读取失败（`duration <= 0`）的曲目并入同名簇，并在组上标记「时长未知」；
- 先跑标签维度；文件名维度中若包含已被标签组认领的文件，整组跳过，避免同一文件出现两次。

### 4.2 保留策略

`pick_keep()` 依次比较：

1. 格式优先级：`.flac` > `.wav` / `.ape` > `.ogg` > `.mp3` > 其他；
2. 同格式下文件更大者。

其余文件进入 `drop`，由流程决定移入 `DUPLICATE_DIR` 或回收站。

### 4.3 声纹与版本碰撞

`soundalike` 的声纹比对与上面的本地规则是**两条独立信号**：

- 声纹对「同一录音换格式/换专辑」最有效；
- 对 Live、Remix、伴奏、不同歌手同伴奏等场景可能给出高相似度；
- 因此声纹结果不能覆盖版本标记。版本标记不同的候选应转人工，不自动移入 `DUPLICATE_DIR`。

完整的碰撞场景与处理策略见 [fingerprint.md](fingerprint.md#6-同曲不同版本的碰撞)。

## 5. 歌词规则

唯一实现：`core/lyrics.py`。

- 歌词文件与音频**同目录、同主文件名**，扩展名 `.lrc`；
- `missing_lrc()` 找出没有同名 `.lrc` 的曲目；
- `orphan_lrc()` 找出没有对应音频的 `.lrc`（按 `config.AUDIO_EXTENSIONS` 判断）；
- 音频移动/改名时，`core.ops.Plan` 会同步搬运同名 `.lrc`。

## 6. 归档规则

唯一实现：`core/organize.py`。

### 6.1 年代标签

`decade_label(year)`：

| 年份 | 目录 |
|---|---|
| ≤ 1979 | `1950-1979` |
| 1980–1989 | `1980-1989` |
| 1990–1999 | `1990-1999` |
| 2000–2009 | `2000-2009` |
| … | 依次类推 |

年份从标签里提取四位数字，合法范围为 1900–2100。

### 6.2 目标路径

```
<目标根>/<年代>/<年份>/<文件名>
```

归档要求歌曲名、歌手、年份齐全；缺少任一项的文件进入 `<目标根>/unknown/`。
注意待补全判定还要求专辑，所以正常情况下进入归档的文件已经满足这些字段。

## 7. 修复范围

`--fix` / 流水线检查阶段的动作严格限制为：

| 动作 | 条件 |
|---|---|
| 重复文件进回收站 | 显式 `--trash-dup` |
| 重复文件移入 `DUPLICATE_DIR` | 未显式回收时 |
| 移入 `INCOMPLETE_DIR` | 仅 `severe`：歌曲名/歌手缺失、文件名与标签矛盾 |
| 文件名规范化 | 单个 `-` 且可安全改写 |
| 改名/移动其余文件 | **不做** |

缺封面、缺专辑、缺年份只写报告，不移动文件——否则一次 `--fix` 可能搬空整个库。

## 8. 报告

唯一实现：`core/report.py`，由 `core/check.py: report_into()` 填充。

- Markdown：汇总各检查项数量，附明细表；
- CSV：待处理清单，列为「类型 / 文件 / 说明」；
- 报告写到 `--report-dir` 或默认 `log/reports/`；
- 报告只描述检查结果，不代替 `log/journal.jsonl` 的实际动作流水。
